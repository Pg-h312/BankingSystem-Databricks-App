# BankingSystem-Databricks-App

An end-to-end **Banking System** built on **Databricks Free Edition (2025)** using **Streamlit, Unity Catalog, Delta Tables, SQL Warehouse, and GitHub Integration**.

## Features

* Customer Management
* Account Management
* Loan Management
* Transaction Tracking
* Payment History
* Banking Dashboard
* Branch Analytics
* Risk Monitoring

## Tech Stack

* Databricks Free Edition
* Streamlit
* Python
* Delta Lake
* Unity Catalog
* Databricks SQL
* GitHub
* SQL Warehouse
